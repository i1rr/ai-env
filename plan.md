# Plan 01: Foundation and CI

Master plan reference: sections 11, 12, 27, 29, 30 (Milestone 1), 31 (Week 1)

## Objective

Produce a working Go CLI binary with `ai-env new` and `ai-env list`, project layout generation, `.gitignore` defaults, YAML config loading, and a passing CI pipeline.

## Dependencies

None. This is the first phase.

## Decisions from master plan

- Language: Go, single binary.
- CLI framework: Cobra.
- Config format: YAML.
- `ai-env new` creates an environment for the current directory or `--from <path>`, not a new application project.
- Default workspace strategy: worktree for Git, copy for non-Git. The workspace manager itself is built in Plan 02; here only the config and skeleton commands are needed.
- Existing config must not be overwritten without `--force`.
- `.ai-env/secrets.local.yaml` is created as a gitignored stub with file mode `0600`, no raw secrets.

## Config files generated by `ai-env new`

Minimal generated `ai-env.yaml`:

```yaml
version: 1
project:
  name: <env-name>
  root: ..
  default_agent: claude
  default_mode: autonomous

workspace:
  strategy: auto
  git_default: worktree
  non_git_default: copy
  branch_prefix: ai-env/
  direct_write: false
  export: patch

sandbox:
  backend: docker-sbx
  fallback_backend: none
  template: <detected-template>
  destroy_on_exit: false
  private_docker_daemon: true
  host_docker_socket: false
  mount_home: false
  accept_reduced_isolation: false

supervision:
  max_runtime_minutes: 120
  idle_timeout_minutes: 20
  shutdown_grace_seconds: 15
  kill_grace_seconds: 5
  max_stdout_bytes: 50000000
  max_stderr_bytes: 50000000
  stream_output_to_disk: true
  max_processes: 1024

logging:
  level: info
  retain_runs: 50
  redact_secrets: true
  run_id_format: timestamp_random_suffix
```

## Acceptance criteria

1. `ai-env new fix-tests` creates `.ai-env/` with all config files.
2. Running `ai-env new fix-tests` a second time without `--force` does not overwrite existing config.
3. `ai-env list` shows created environments without starting any backend process.
4. `.gitignore` entries protect workspaces, runs, cache, and local secrets.
5. `.ai-env/secrets.local.yaml` has no raw credentials and is mode `0600`.
6. CI pipeline passes: tests, lint, vet, security check.
7. Binary builds on macOS and Linux.
